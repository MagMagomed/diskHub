# DiskHub

Локальное веб-приложение для загрузки и хранения фотографий и других файлов.
Пользователи регистрируются по адресу электронной почты и паролю, после чего
видят только файлы своего аккаунта. Отображаемое имя можно задать при
регистрации и изменить позднее в шапке личного пространства; для входа
используется адрес электронной почты.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте адрес Vite, показанный в терминале (обычно `http://localhost:5173`).
Файлы каждого аккаунта сохраняются в отдельной папке
`uploads/<идентификатор-пользователя>/`. Папки создаются автоматически.
Данные аккаунтов и хеши паролей находятся в `data/users.json`; пароль
сохраняется в виде хеша scrypt с уникальной солью. Эти данные и загруженные
файлы исключены из Git.

Для production-сборки выполните `npm run build`, затем `npm start`. Приложение
будет доступно на `http://localhost:3001`.

За одну загрузку можно отправить до 20 файлов размером не более 100 МБ каждый.
Пароль должен содержать от 10 до 128 символов. Сессия хранится в защищённой от
чтения JavaScript cookie сроком на 7 дней; после перезапуска сервера потребуется
войти снова. Файлы, оставшиеся в корне `uploads/` от версии без аккаунтов, не
показываются ни одному пользователю.

В форме регистрации можно сгенерировать случайный пароль и после регистрации
или входа сохранить его в менеджере паролей браузера. Сохранение доступно в
совместимых браузерах на защищённом соединении; если браузер не поддерживает
Credential Management API, приложение сообщит об этом.
Имя пользователя может содержать от 2 до 40 букв, цифр, пробелов, точек,
дефисов или подчёркиваний.

## Роли и права доступа

У нового аккаунта роль `Customer`: он может просматривать, загружать и удалять
только свои файлы. `System Customizer` может просматривать список всех аккаунтов,
их роли и файлы, а также скачивать и удалять файлы пользователей. Администратор
видит отдельную панель управления после входа.

Повысить роль можно только с доступом к серверу. Остановите приложение и
выполните команду из корня проекта:

```bash
npm run role:set -- admin@example.com "System Customizer"
```

Для назначения обычной роли используйте `"Customer"`. После изменения роли
перезапустите сервер, чтобы обновить активные сессии. Роли не принимаются из
запроса регистрации и не изменяются пользователем через API.
